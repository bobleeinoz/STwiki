# SFRC durability, fire and production control

> Scope: AS 3600 Cl 16.5 (durability), Cl 16.6 (fire), Cl 16.7 (production —
> pre-construction testing, factory production control, fibre-content
> determination, conformance/acceptance).

## Summary

`[code]` Cover and concrete grade for exposure classifications A, B1 and B2
are unaffected by fibres — normal Section 4 rules apply to the steel
reinforcement only (Cl 16.5). In exposure classifications C1, C2 and U,
fibres present must be **disregarded** in ULS strength calculations. Fibres
never need concrete cover per Cl 4.10.3, and SFRC may not suit some
exposure-U environments. Fire performance follows Section 5 in full (Cl
16.6) — see [[as3600-fire-resistance-design]].

## Detail

### Fibres and mixing (Cl 16.7.1–16.7.2)

`[code]` Steel fibres conform with ISO 13270:2013 (EN 14889-1 fibres are
deemed to comply); a current Declaration of Performance must be available on
request. Fibres are added by a controlled process ensuring uniform
dispersion; if added after main mixing, the batch is remixed until fully
dispersed. Fibre balling should be avoided and fibre content recorded per
batch.

### Pre-construction testing (Cl 16.7.3, Table 16.7.3)

`[code]` Initial type tests are required per Table 16.7.3, repeated whenever:
concrete composition changes; any source material changes; AS 1379
compressive results fail; or at least every 12 months. Tests use the same
materials/equipment as production.

![[as3600-table-16.7.3-preconstruction-tests.png]]
*Table 16.7.3 — pre-construction (initial type) tests for SFRC
(AS 3600:2018).*

| Material | Inspection/test | Purpose |
| --- | --- | --- |
| Steel fibres | Record/document delivery note | Verify delivery matches order and source |
| Steel fibres | Check/record ISO 13270 conformance | Verify correct ISO/CE label |
| Fibre content in fresh concrete | EN 14721 + Cl 16.7.5, 9 samples | Conformity with target dosage; homogeneous distribution |
| SFRC performance | Limit of proportionality + post-crack flexural strength per EN 14651, ≥6 beams | Verify performance vs specification; sets the production-control reference |

### Factory production control (Cl 16.7.4, Table 16.7.4)

`[code]` Ongoing control covers: correct constituents; fibres checked
against ISO/CE labelling; AS 1379 compressive tests; fibre content and
distribution (fibre type/dosage shown on the delivery docket). Table 16.7.4
sets frequencies — dosing-equipment inspection (visual: daily; accuracy: on
install/periodically/on doubt); materials inspection (delivery note, ISO/CE
label, fibre geometry: each delivery); fibre content in fresh concrete
(beginning of each day + every 50 m³ manual/150 m³ auto dosing); concrete
mix visual check (daily); fibre-content record and SFRC performance check
(every batch; ≥6 beams per 12-month period respectively).

![[as3600-table-16.7.4-routine-production-control.png]]
*Table 16.7.4 — routine production control frequencies for SFRC
(AS 3600:2018).*

### Determining fibre content and acceptance (Cl 16.7.5–16.7.6, Table 16.7.5)

`[code]` Fibre content is measured per EN 14721 from samples taken at
unloading (first/middle/final third of the batch, ≥7 L each, filled in one
continuous pour directly from the discharge chute where possible), using
wash-out, magnetic separation or validated automated dosing equipment.

![[as3600-table-16.7.5-criteria-acceptance-fibre-dosage.png]]
*Table 16.7.5 — criteria of acceptance for steel fibre dosage
(AS 3600:2018).*

| Frequency | Test control | Criteria |
| --- | --- | --- |
| Each sample | Each partial test | ≥0.80 of specified target dosage |
| Average of 3 samples/batch | Each test | ≥0.80 of specified target dosage |
| Continuous control | Average of >3 tests | ≥0.90 of specified target dosage |

`[code]` Where concrete is specified by parameters other than strength grade
(Cl 16.7.6, mirroring Cl 17.1.6.3), the control/assessment method must give
an operating characteristic curve such that a 0.05-proportion-defective
population has ≥50% acceptance probability, and a 0.30-proportion-defective
population has ≥98% rejection probability.
