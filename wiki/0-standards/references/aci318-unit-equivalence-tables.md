# ACI 318M-19 Appendix C — equivalence of SI, MKS and US customary non-homogeneous equations

> Raw lookup table reproduced as page images from ACI 318M-19 Appendix C (a data page, so it is filed in
> `references/` per CLAUDE.md). **ACI 318M-19 page, kept separate from the AS 3600:2018 pages**
> (see [[aci-318m-19-building-code-concrete]]).

## Summary

`[code]` Appendix C gives, for each Code provision whose equation is not dimensionally homogeneous
(typically containing `√f'c` or a numerical constant tied to a unit system), the equivalent form in SI-metric
(stress in MPa), mks-metric (stress in kgf/cm²) and U.S. customary units (stress in psi). Rows are keyed by
provision number, running from Cl 6.6.4.5.4 through Cl 25.9.4.5.1 and Appendix A (Cl A.10.2b, A.11.3.2).
The opening rows give the basic conversions of strength values (e.g. 1 MPa = 10 kgf/cm² = 145 psi and the
corresponding `f'c`, `f_y`, `f_pu` values).

Use it to check an equation read from another edition or unit system. The wiki's concept pages quote
the **SI-metric** forms (ACI 318M-19) only.
