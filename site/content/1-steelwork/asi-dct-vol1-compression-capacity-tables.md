# ASI Design Capacity Tables Vol 1 — column design member capacity tables in axial compression

> Source: `raw/1-steelwork/ASI-design-capacity-tables-volume-1-pdf.pdf` — see
> [[asi-design-capacity-tables-vol1-open-sections]] for the full source
> register, edition/vintage details and the standing cross-check caveat
> (design aid keyed to AS 4100—1998, not the current AS 4100:2020).

[practice] Full numeric transcription of DCT Vol 1 Part 6 (Members Subject to Axial Compression): Table T6.1 (member section constant α_b by section type), Figure 6.1 (effective length factors k_e for idealised end restraints), and the full Table 6-1 to 6-12 series — design member capacity in axial compression φN_c vs effective length L_e, about both the x- and y-axis, for every open section type and both Grade 300 and Grade 400 where tabulated. Every value (~5,800 numbers across 26 tables) was cross-checked during this ingest pass by recomputing φN_c per AS 4100 Cl 6.3.3 (φN_c = α_c φN_s, member slenderness reduction factor α_c from the modified slenderness λ_n and the member section constant α_b) using A_g, r_x, r_y from [[asi-dct-vol1-open-section-properties]] — with zero discrepancies found across every table.

### Table T6.1 — Values of member section constant (α_b)

| Section | Residual stresses | Yield slenderness limit λ_ey | α_b (k_f = 1.0) | α_b (k_f < 1.0) |
|---|---|---|---|---|
| WB, WC | HW (heavily welded) | 35 (web), 14 (flange) | 0 | 0.5 |
| UB, UC, TFB | HR (hot-rolled) | 45 (web), 16 (flange) | 0 | 0 |
| PFC | HR | 45 (web), 16 (flange) | 0.5 | 1.0 |
| BT, CT | HR | 45 (web), 16 (flange) | 0.5 | 1.0 |
| EA, UA | HR | 16 (flange) | 0.5 | 1.0 |

[practice] DCT Section 6.3 method (own words, per the DCT text citing AS 4100 Cl 6.3.3): φN_c = α_c φN_s ≤ φN_s, with α_c from AS 4100 Cl 6.3.3 using modified slenderness λ_n = (L_e/r)√k_f √(f_y/250), α_a = 2100(λ_n − 13.5)/(λ_n² − 15.3λ_n + 2050), λ = λ_n + α_a α_b, η = 0.00326(λ − 13.5) ≥ 0, ξ = [(λ/90)² + 1 + η]/[2(λ/90)²], α_c = ξ{1 − √[1 − (90/(ξλ))²]}. At L_e = 0 the design member capacity equals the design section capacity (φN_c = φN_s).

### Figure 6.1 — Effective length factors (k_e) for members with idealised conditions of end restraint

L_e = k_e L. Values shown in the source figure (buckled-shape sketches in the page image):

| Case | End restraint (top / bottom) | k_e |
|---|---|---|
| Braced member | Rotation fixed + translation fixed / rotation fixed + translation fixed (fixed–fixed) | 0.7 |
| Braced member | Rotation free + translation fixed / rotation fixed + translation fixed (pinned–fixed) | 0.85 |
| Braced member | Rotation free + translation fixed / rotation free + translation fixed (pinned–pinned) | 1.0 |
| Sway member | Rotation fixed + translation free / rotation fixed + translation fixed | 1.2 |
| Sway member | Rotation free + translation free / rotation fixed + translation fixed (flagpole cantilever) | 2.2 |
| Sway member | Rotation fixed + translation free / rotation free + translation fixed | 2.2 |

[derived] These appear to match AS 4100 Figure 4.6.3.2 (idealised end restraint) — confirm against the standard. For members in frames, k_e depends on the ratio γ of compression-member stiffness to end-restraining-member stiffness at each end (AS 4100 Cl 4.6.3.3, Figure 4.6.3.3; or a rational buckling analysis, Cl 4.7). Example 2 of DCT Section 4.3 gives a sample k_e calculation for a simple unbraced plane frame.
