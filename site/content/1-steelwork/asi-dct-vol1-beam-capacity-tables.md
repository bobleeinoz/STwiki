# ASI Design Capacity Tables Vol 1 — beam design load and moment capacity tables

> Source: `raw/1-steelwork/ASI-design-capacity-tables-volume-1-pdf.pdf` — see
> [[asi-design-capacity-tables-vol1-open-sections]] for the full source
> register, edition/vintage details and the standing cross-check caveat
> (design aid keyed to AS 4100—1998, not the current AS 4100:2020).

[practice] Full numeric transcription of DCT Vol 1 Part 5 (Members Subject to Bending) for every open section type: Table T5.1 (equivalent UDL conversion), Table T5.2 (welded-joint shear capacity), Table T5.3 (deflection formulae), the 5.1-series maximum-design-UDL tables (simply-supported beam with full lateral restraint — strength W*_L1/W*_L2 and serviceability W*_S), the 5.2-series design section moment and web capacities (φM_sx, φM_sy, φV_v, web bearing), and the 5.3-series design member moment capacities without full lateral restraint (φM_b vs effective length L_e, α_m = 1). Every value in the 5.1 and 5.3 series (about 3,700 numbers across ~35 tables) was cross-checked during this ingest pass by recomputing from AS 4100 first principles — φM_b via the elastic flexural-torsional buckling formula (Cl 5.6.1.1, α_m = 1) using the section's I_y, J, I_w from [[asi-dct-vol1-open-section-properties]], and W*_L1 = 8φM_sx/L, W*_S ≈ min(deflection-limit UDL, first-yield UDL) — with zero discrepancies found except one isolated source print anomaly noted inline (700WB115, W*_S at 5.0 m span). The 5.2-series values were spot-checked against φM_sx = 0.9·f_y·Z_ex with zero discrepancies.

### Table T5.1 — Equivalent uniform design loads (simply supported beam, span L)

Convert a point-load pattern to an equivalent total UDL, then compare against the maximum design load tables (5.1 series). W*_EM = equivalent UDL for moment; W*_EV = equivalent UDL for shear; W*_ES = equivalent UDL for serviceability (deflection).

| Loading | W*_EM (moment) | W*_EV (shear) | W*_ES (serviceability) |
|---|---|---|---|
| Single load P at midspan | 2P | P | 8P/5 |
| Single load P at distance a from one support (a < b, a + b = L) | 8abP/L² | 2Pa/L | (8P/5)[3(a/L) − 4(a/L)³] at midspan |
| Two loads P, each at distance a from the supports | 8aP/L | 2P | (16P/5)[3(a/L) − 4(a/L)³] |
| Three loads P at L/4 spacing (quarter points) | 4P | 3P | 19P/5 |
| Four loads P at L/5 spacing | 24P/5 | 4P | 3024P/625 |

[derived] The shear column equals 2 × (maximum end reaction), matching a UDL W whose end shear is W/2 (e.g. central P → reaction P/2 → W*_EV = P). For the single eccentric load (a < b) the larger reaction is Pb/L, which would give W*_EV = 2Pb/L; the source prints 2Pa/L. This looks like a possible source misprint that would be unconservative. It is flagged for human check against the page image and has not been corrected here.

### Table T5.3 — Beam deflection formulae

W = total load on beam; L = span; E = Young's modulus; I = second moment of area; Δ = maximum deflection.

| Support | Loading | Δ |
|---|---|---|
| Simply supported | UDL, total W | (5/384) WL³/EI |
| Simply supported | Triangular load peaking 2W/L at midspan (total W) | (1/60) WL³/EI |
| Simply supported | Point load W at midspan | (1/48) WL³/EI |
| Simply supported | Point load W at distance a from support | (WL³/48EI)[3a/L − 4(a/L)³] |
| Simply supported | n spaces of L/n, each force W/(n−1) | k WL³ / [192(n−1) EI]; n odd: k = (n − 1/n)[3 − ½(1 − 1/n²)]; n even: k = n[3 − ½(1 + 4/n²)] |
| Built-in (fixed both ends) | UDL, total W | (1/384) WL³/EI |
| Built-in | Triangular load peaking 2W/L at midspan | (1.4/384) WL³/EI |
| Built-in | Point load W at midspan | (1/192) WL³/EI |
| Built-in | n spaces of L/n, each force W/(n−1) | k WL³ / [192(n−1) EI]; n odd: k = (n − 1/n)[1 − ½(1 − 1/n²)]; n even: k = [3 − ½(1 + 4/n²)] × n − [2(n − 1/n)] |
| Cantilever | UDL, total W | (1/8) WL³/EI |
| Cantilever | Triangular load, 2W/L at root reducing to 0 at tip | (1/15) WL³/EI |
| Cantilever | Point load W at distance a from root (b = L − a beyond) | (Wa³/EI)(1/3)[1 + 3b/(2a)] (tip deflection) |
